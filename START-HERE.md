# Start here

1. Read **`README.md`** for scope and exclusions.
2. Open **`BOOK-COMPANION-NOTES.md`** for chapter → file mapping.
3. Pick **one** template from **`templates/`** and duplicate it before editing (keep blanks reusable).
4. Skim **`SAFETY.md`** before pasting anything from real systems into examples.

This companion supports practice only—it is **not** policy, legal guidance, security incident authority, or a substitute for organizational review gates.
