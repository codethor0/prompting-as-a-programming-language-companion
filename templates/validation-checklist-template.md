# Validation checklist — template

## Purpose
Operational tests that outputs are plausible, coherent, on-contract, safe enough to forward.

## When to use
Before every handoff deemed “done enough”.

## Inputs
Baseline truth sources, reviewer availability, allowable tools.

## Output artifact
Checklist result log (**DRAFT — HUMAN_REVIEW_REQUIRED** until filed).

## Constraints
Cheap checks before expensive polish.

## Forbidden assumptions
“Adequate tone” substitutes for structural correctness.

## Validation checks *(examples)*
- [ ] Contract coverage  
- [ ] Internal consistency  
- [ ] Redaction / privacy posture  
- [ ] Citation-to-source trace (where applicable)  

## STOP_CONDITIONS
Any failed critical check blocks progression.

## Human review
Escalation path for disagreements.

## Version notes
Template major/minor

Unknown scoring weights for risk acceptance
