# Input / output contract — template

## Purpose
Declarative handshake: what crosses the boundary in and what must emerge.

## When to use
Stakeholders disagree on scope or outputs drift between runs.

## Inputs
- Declared domains of allowed context  
- Prohibited data classes  

## Output artifact
Schema or bullet checklist describing acceptable deliverable (**DRAFT — HUMAN_REVIEW_REQUIRED**).

## Constraints
Treat model output as probabilistic artifact until validated.

## Forbidden assumptions
Silent acceptance of pasted metrics without lineage.

## Validation checks
- [ ] Outputs map explicitly to declared inputs  
- [ ] UNKNOWN marks missing facts  

## STOP_CONDITIONS
Stop if contractual inputs incomplete or classifications unclear.

## Human review
Sign-off owner for releasing contract to automation.

## Version notes
Contract revision string  

## QUESTIONS_FOR_OWNER
Ambiguous wording that could widen scope unintentionally
