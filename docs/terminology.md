# Terminology recap

Abbreviated glossary aligned with POP language in *Prompting as a Programming Language*.

| Term | Reminder |
|------|----------|
| **Prompt block** | Named unit capturing intent + I/O framing |
| **Prompt chain** | Ordered blocks linked by artefacts |
| **UNKNOWN** | Deliberate admission of ignorance |
| **QUESTIONS_FOR_OWNER** | Blocking questions for accountable human |
| **STOP_CONDITIONS** | Preconditions halting risky continuation |
| **STATE_CHANGE** | Durable mutations requiring human stewardship |
| **DRAFT — HUMAN_REVIEW_REQUIRED** | Non-final posture label |
