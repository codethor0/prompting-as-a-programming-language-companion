# How to use this companion

1. **Keep it private** until author-approved release — **`PRIVATE-UNTIL-APPROVED.md`**.  
2. **Branch work per workflow** rather than accumulating one mega chat.  
3. **Paste fictional fixtures first** (`fixtures/`), then escalate complexity only inside **your org’s** sanctioned sandboxes with redaction enforced.  
4. **Treat model output like unmerged code**: tests (validation checklist) precede merges to anything customer-visible.  
5. **Iterate templates** deliberately—update **`version-record-template.md`** lineage when patterns evolve.  

Never rely on workbook Markdown for jurisdictional interpretations.
