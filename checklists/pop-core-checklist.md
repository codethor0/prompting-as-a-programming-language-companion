# POP core checklist *(workbook mirror — not the retail appendix text)*

Use alongside **Appendix B** in the book. This file is a **parallel practice sheet**; when in doubt, prefer the published manuscript.

- [ ] **Prompt block** names purpose, inputs, outputs, failure behavior  
- [ ] **Chain** handoffs carry validation receipts  
- [ ] **UNKNOWN** used instead of guesses  
- [ ] **QUESTIONS_FOR_OWNER** surfaced early  
- [ ] **STOP_CONDITIONS** explicit before automation  
- [ ] **Tool** calls least-privilege with logged intent  
- [ ] **Validation** distinguishes facts vs hypotheses  
- [ ] **Human review** before external send / mutate / publish  
- [ ] **Version / library** breadcrumb captured when reusing artefacts  
- [ ] Security boundary reviewed for injection / data-class leaks
